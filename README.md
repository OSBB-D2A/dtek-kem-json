# DTEK Kyiv JSON test collector

Тестовий GitHub Actions-проєкт для отримання JSON-відповіді графіків ДТЕК Київські електромережі для вулиці **Донця Михайла**.

Збір виконується через **Playwright + Chromium**: скрипт відкриває сайт у браузерному контексті, а потім виконує запит `getHomeNum` з тієї самої сторінки. Це повторює корисний підхід проєкту [Baskerville42/outage-data-ua](https://github.com/Baskerville42/outage-data-ua), де браузер допомагає отримати справжню сторінку та встановити сесію. Це не гарантує проходження WAF/CAPTCHA: якщо DTEK відхиляє запит, запуск фіксує помилку, а не записує challenge як дані.

## Запуск

1. Відкрийте **Actions** → **DTEK JSON test**.
2. Натисніть **Run workflow**.
3. Після завершення відкрийте запуск і завантажте артефакт `dtek-json-test`.
4. Перевірте `run-summary.json`. Якщо всі спроби не вдалися, `diagnostics.json` міститиме короткий фрагмент отриманої сторінки для діагностики.

## Файли результату

- `dtek-response.json` — оригінальна повна JSON-відповідь DTEK.
- `dtek-street.json` — усі будинки вулиці в полі `data`, кількість записів і час оновлення.
- `dtek-2a.json` — окремий запис для будинку **2A** (підтримується ключ як латиницею `2A`, так і кирилицею `2А`).
- `run-summary.json` — статус запуску, кількість будинків, спроба та чи знайдений будинок 2A.
- `diagnostics.json` — діагностика останньої невдалої спроби; може містити фрагмент HTML відповіді сервера.

Якщо будинок 2A не знайдено, `dtek-2a.json` усе одно буде створено з `found: false`, а повний список вулиці збережеться. Якщо збір завершується помилкою, попередні файли з даними не перезаписуються.

## Налаштування

За замовчуванням:
- `DTEK_URL=https://www.dtek-kem.com.ua/ua/shutdowns`
- `DTEK_STREET=вул. Донця Михайла`
- `DTEK_BUILDING=2A`
- `DTEK_MAX_ATTEMPTS=3`

Значення можна змінити у змінних середовища workflow. Періодичний запуск поки вимкнений до успішного ручного тесту.

**Безпека:** не додавайте до репозиторію cookies, CSRF-токени, паролі або інші сесійні дані.
