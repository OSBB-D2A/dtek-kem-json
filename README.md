# DTEK Kyiv JSON test collector

Тестовий GitHub Actions-проєкт для отримання JSON-відповіді графіків ДТЕК Київські електромережі для вулиці **Донця Михайла**.

**Важливо:** скрипт не обходить CAPTCHA / Imperva. Якщо сайт повертає сторінку перевірки або помилку доступу, запуск завершиться помилкою й не збереже HTML під виглядом JSON.

## Запуск

1. Відкрийте **Actions** → **DTEK JSON test**.
2. Натисніть **Run workflow**.
3. Після завершення відкрийте запуск і завантажте артефакт `dtek-json-test`.
4. У ньому будуть `run-summary.json` та JSON-файли з даними.

## Файли результату

- `dtek-response.json` — оригінальна повна JSON-відповідь DTEK.
- `dtek-street.json` — всі будинки вулиці в полі `data`, кількість записів і час оновлення.
- `dtek-2a.json` — окремий запис для будинку **2A** (підтримується ключ як латиницею `2A`, так і кирилицею `2А`).
- `run-summary.json` — статус запуску, кількість будинків і чи знайдений будинок 2A.

Якщо будинок 2A не знайдено, `dtek-2a.json` усе одно буде створено з `found: false`, а повний список вулиці збережеться.

## Налаштування

За замовчуванням:
- `DTEK_URL=https://www.dtek-kem.com.ua/ua/shutdowns`
- `DTEK_STREET=вул. Донця Михайла`
- `DTEK_BUILDING=2A`

Значення можна змінити в змінних середовища workflow.

Періодичний запуск поки вимкнений до успішного ручного тесту.

**Безпека:** не додавайте до репозиторію cookies, CSRF-токени, паролі або інші сесійні дані.
