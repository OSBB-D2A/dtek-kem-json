# DTEK Kyiv JSON test collector

Тестовий GitHub Actions-проєкт для перевірки, чи вдається отримати дані графіка відключень ДТЕК Київські електромережі та зберегти відповідь у JSON.

**Важливо:** скрипт не обходить CAPTCHA / Imperva. Якщо сайт повертає сторінку перевірки або помилку доступу, запуск завершиться помилкою й не збереже HTML під виглядом JSON.

## Запуск

1. Відкрийте **Actions** → **DTEK JSON test**.
2. Натисніть **Run workflow**.
3. Після завершення відкрийте запуск і завантажте артефакт `dtek-json-test`.
4. У ньому буде `run-summary.json`, а за успіху — `dtek-response.json`.

Періодичний запуск поки вимкнений до успішного ручного тесту. Після перевірки розкоментуйте `schedule` у `.github/workflows/dtek-test.yml`.

За замовчуванням тестує вулицю **Донця Михайла**. Налаштування доступні через змінні середовища `DTEK_URL` і `DTEK_STREET`.

Не додавайте до репозиторію cookies, CSRF-токени, паролі або інші сесійні дані.
