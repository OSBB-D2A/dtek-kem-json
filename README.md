# DTEK Kyiv — збір даних про відключення

GitHub Actions-проєкт для отримання та збереження JSON-даних про планові й аварійні відключення ДТЕК Київські електромережі для вулиці **Донця Михайла**, зокрема будинку **2А**.

Збір виконується через **Playwright + Chromium**: скрипт відкриває сайт у браузерному контексті, а потім виконує запит до AJAX endpoint з тієї самої сторінки. Такий підхід допомагає встановити сесію браузера. Він не гарантує проходження WAF/CAPTCHA: якщо DTEK відхиляє запит, запуск фіксує помилку, а не записує challenge як дані.

## Запуск вручну

1. Відкрийте **Actions** → **DTEK — збір даних про відключення**.
2. Натисніть **Run workflow**.
3. Після завершення відкрийте запуск і завантажте артефакт `dtek-kem-data`.
4. Перевірте `run-summary.json`. Якщо збір не вдався, `diagnostics.json` міститиме діагностичні відомості про відповідь сервера.

## Файли результату

- `dtek-response.json` — повна JSON-відповідь DTEK.
- `dtek-street.json` — дані по будинках вулиці та час оновлення.
- `dtek-2a.json` — окремий запис для будинку **2А** (підтримується ключ як латиницею `2A`, так і кирилицею `2А`).
- `run-summary.json` — статус запуску, кількість будинків, номер спроби та інформація про пошук цільового будинку.
- `diagnostics.json` — діагностика невдалої спроби; може містити фрагмент HTML-відповіді сервера.

Якщо будинок 2А не знайдено, `dtek-2a.json` усе одно буде створено з `found: false`, а повний список вулиці збережеться. Якщо збір завершується помилкою, попередні файли з даними не перезаписуються.

## Налаштування

За замовчуванням:
- `DTEK_URL=https://www.dtek-kem.com.ua/ua/shutdowns`
- `DTEK_STREET=вул. Донця Михайла`
- `DTEK_BUILDING=2A`
- `DTEK_MAX_ATTEMPTS=3`

Значення можна змінити у змінних середовища workflow. Періодичний запуск поки вимкнений; його слід увімкнути окремим кроком після завершення перевірок стабільності.

**Безпека:** не додавайте до репозиторію cookies, CSRF-токени, паролі або інші сесійні дані.
